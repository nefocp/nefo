# 路线图

Nefo 的路线图没有日期：一项功能能用了才会发布。在 1.0 版本之前，工作的重点是让现有功能可靠：在真实的 ARM64 硬件上和真实的服务上测试，让一台测试服务器长时间运行，收集外部用户的报告，以及做一次外部安全审查。有些想法正在考虑中，还有少数几件事有意不做。

本页列出正在进行的工作、正在考虑的想法，以及 Nefo 不会做的事。已经发布的内容见 [更新日志](./changelog)。

## 现在：迈向 1.0 {#now-toward-1-0}

Nefo 处于测试阶段（beta）。在 1.0 版本之前，工作更多地放在让现有功能可靠上，而不是新功能上：

- **在 ARM64 上测试安装程序**。安装程序（无论是否同时配置软件）已在全新的 Ubuntu 22.04、24.04、26.04 和 Debian 12、13 服务器上测试过，平台为 x86-64。ARM64 版本已经发布，但还没有在真实的 ARM 硬件上测试过。
- **在真实的服务上测试**。备份到 S3 兼容存储（例如 AWS S3 和 Cloudflare R2）和 Google Drive，通过 Telegram、Discord、Slack 和 Webhook 发送告警，通过 SMTP 服务商发送邮件，以及 Cloudflare API。其中有些到目前为止只在替身上测试过：例如 Google Drive 只在模拟的 Google 服务上测试过。
- **让一台测试服务器长时间运行**，上面放真实的网站，这样需要几周才会显现的问题（不断增长的日志、磁盘占用、内存）能在你遇到之前被发现。
- **外部用户及其 bug 报告**。每份带重现步骤的报告都有帮助。见 [报告 bug](./about#get-help-and-report-bugs)。
- **一次外部安全审查**。还没有做过外部审计。在此之前，请把 Nefo 看作以 root 身份运行的测试阶段软件，并参阅 [安全策略](./security-policy)。

在 1.0 版本之前，只有最新的发布版本会获得安全修复。

## 正在考虑 {#being-considered}

这些是想法，不是承诺。有些可能会变，有些可能永远不会发布。

- **不需要你自己的 OAuth 客户端的 Google Drive 备份**。目前每台服务器都需要一个你在 Google Cloud 项目中创建一次的 OAuth 客户端（见 [Google Drive](./docs/backups#google-drive)）。
- **在 Cloudflare 代理后面使用访客自己的地址**，在 Nginx 上的网站日志和 PHP 中，作为每个网站的一项设置。目前，Nginx 上位于代理后面的网站在那里看到的是 Cloudflare 的地址；国家/地区拦截已经会查询访客的地址。
- **更沉稳的面板界面**。

面板支持七种语言。欢迎翻译成更多语言：见 [CONTRIBUTING.md](https://github.com/nefocp/nefo/blob/main/CONTRIBUTING.md)。

## 不打算做的事及原因 {#not-planned-and-why}

Nefo 要保持足够轻量，能在 1 GB 内存的 VPS 上运行，也要保持足够小，让它的代码可以接受安全检查。下面每一项都会增加一直运行的服务、对互联网开放的端口，或者大量以 root 运行的代码。所以它们被有意排除在外，本页也会说明 Nefo 提供了什么替代方案。

| 不打算做 | 原因 | Nefo 提供的替代方案 |
|---|---|---|
| 邮件服务器 | 邮件需要多个服务一直运行，需要占用大量内存的垃圾邮件和病毒过滤，还要持续维护服务器的信誉。很多服务商还会封锁外发的 25 端口。 | 通过你的邮件服务商的 SMTP 中继，供网站和告警使用。邮箱请使用邮件服务商。见 [邮件与告警](./docs/mail-alerts)。 |
| DNS 服务器 | 域名服务器必须一直从互联网响应，最好运行在不止一台机器上。 | 在面板中管理你的 Cloudflare 区域的 DNS 记录，以及通过 Cloudflare DNS 获取通配符证书。见 [DNS（Cloudflare）](./docs/dns)。 |
| FTP 服务器 | 又一个有自己开放端口和自己账户的服务。 | 每个网站一个 SFTP 账户，限制在网站的文件夹内，使用密码或 SSH 密钥。见 [SFTP 访问](./docs/websites#sftp-access)。 |
| 在一个面板中管理多台服务器 | 控制其他服务器的面板需要代理程序，还需要机器之间互相信任。入侵其中一台就能波及所有机器。 | 每台服务器一个 Nefo。API 密钥让你自己的脚本可以操作每台服务器。见 [API 密钥](./docs/api)。 |
| 代理商和主机客户账户 | 带有各自限额、套餐和配额的账户是另一种产品，用于出售主机服务。Nefo 是给运行服务器的人用的。 | 一个管理员账户。要让客户上传文件，请为他们的网站开一个 SFTP 账户。 |

如果你需要其中某一项，其他面板可能更适合你：见 [Nefo 与其他面板](./compare#when-another-panel-fits-you-better)。
