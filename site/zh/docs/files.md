# 文件

Nefo 的 **文件** 页面是一个浏览器中的文件管理器：浏览目录，编辑最大 2 MB 的文本文件，一次上传最多 4 GB，下载文件，从 URL 获取文件，按名称或内容搜索，压缩和解压，并从保留 30 天的回收站中恢复已删除的项目。在网站的文件夹中，它以网站用户的身份工作，不能离开该文件夹。

本页逐一介绍这些功能。面板以 root 身份运行，所以本页也会说明你可以访问哪些位置，以及它拒绝更改什么。

## 浏览目录 {#find-your-way}

文件管理器打开时位于 `/var/www`，每个网站在这里都有自己的文件夹 `/var/www/example.com`。

- 点击文件夹名称即可打开它。**上一级** 返回上级文件夹，**刷新** 重新读取当前文件夹。
- 顶部路径的每一段都可以点击。房子按钮（**网站**）带你回到 `/var/www`。
- 要直接跳到某个文件夹，点击铅笔按钮（**输入路径**），输入绝对路径（例如 `/etc/nginx`），然后点击 **前往**。
- 表格显示 **名称**、**大小**、**权限**、**属主** 和 **修改时间**。项目超过 5,000 个的文件夹只显示前 5,000 个。

## 你可以访问哪些位置 {#what-you-can-reach}

在网站文件夹之外，你以 root 身份操作整个文件系统。

在网站的文件夹 `/var/www/example.com` 中，所有操作都被限制在该文件夹内，路径旁边会出现一个带域名的标记：

- 路径不能用 `..` 跳出去，符号链接也不能指向文件夹之外。被入侵的网站即使放了一个指向 `/etc` 的链接，也无法骗面板去动系统文件。
- 新建的文件和文件夹属于网站用户，所以它的 PHP 可以使用它们。
- 在网站文件夹和任何其他文件夹之间移动、压缩或解压会被拒绝。请改为下载文件，再把它上传到需要的地方。
- 网站的 [文件被锁定](./website-protection#lock-a-website-s-files) 期间，你只能更改它的可写文件夹以及 `tmp` 和 `logs` 文件夹。在网站文件夹的其他位置，文件管理会拒绝操作，并提示文件已锁定。

以下文件夹不能删除、重命名或更改权限：

- `/`、`/bin`、`/boot`、`/dev`、`/etc`、`/home`、`/lib`、`/lib64`、`/opt`、`/proc`、`/root`、`/run`、`/sbin`、`/srv`、`/sys`、`/tmp`、`/usr`、`/var`；
- `/var/www`、`/var/lib`、`/var/log`、`/var/lib/nefo` 和 `/etc/nefo`；
- 每个网站自己的文件夹，例如 `/var/www/example.com`（其中的文件可以更改）；
- 回收站文件夹 `/var/lib/panel-trash`，以及包含它的文件夹。

## 编辑文件 {#edit-a-file}

1. 点击文件名称。它会在编辑器中打开。
2. 进行修改。Ctrl+S 保存，Tab 键插入制表符。
3. 点击 **保存**，然后点击 **关闭**。

编辑器可以打开最大 2 MB 的文本文件。二进制文件和更大的文件会被拒绝：请改为下载它们。保存后的文件保留原来的权限和属主。如果有未保存的更改时关闭编辑器，面板会先询问。

要创建文件，点击 **新建文件**，在 **新文件名称** 中输入名称，然后点击 **确定**。要创建文件夹，点击 **新建文件夹**。新文件的权限为 `0644`，新文件夹为 `0755`。

## 上传文件 {#upload-files}

1. 打开要上传到的文件夹。
2. 点击 **上传**，选择一个或多个文件。
3. 如果已有同名文件，面板会在替换之前先询问。

进度条会显示上传进度。一次上传总共最多 4 GB。上传的文件权限为 `0644`。在网站文件夹中，它们属于网站用户，在其他位置属于 root。

## 下载文件 {#download-a-file}

打开文件的菜单，点击 **下载**。只能下载文件。要下载文件夹，请先压缩它。

## 从 URL 下载 {#download-from-a-url}

服务器可以直接从互联网把文件获取到某个文件夹中，不经过你的电脑。

1. 打开目标文件夹，点击 **从 URL 下载**。
2. 输入 **文件地址（URL）**，然后点击 **下载**。
3. 日志会显示进度。你可以点击 **隐藏（下载继续进行）**。

规则：

- 只支持 `http` 和 `https` 地址，最多 5 次重定向。
- 文件最大 2 GB。
- 面板永远不从服务器自己的网络下载：回环地址、私有地址和链路本地地址（例如 `127.0.0.1`、`10.x.x.x` 和 `169.254.169.254`），以及服务器自己的地址，都会被拒绝。每次重定向都会再次检查。
- 文件名来自服务器或 URL。已有的文件永远不会被替换：面板会加上 ` (1)`、` (2)` 等。
- 文件属于该文件夹的属主，权限为 `0640`。

## 搜索 {#search}

1. 打开要在其中搜索的文件夹。
2. 在搜索框（**搜索此文件夹**）中输入内容，然后按 Enter。
3. 在对话框中调整 **名称包含**。要搜索文件中的文本，勾选 **同时搜索文件内容**，并填写 **文件中的文本**。
4. 点击 **搜索**。

不区分大小写。点击结果会打开它所在的文件夹。文本文件还会在编辑器中打开。

为了不让一次搜索占住服务器，有以下限制：

| 限制 | 值 |
|---|---|
| 检查的项目 | 20,000 个 |
| 结果 | 200 个 |
| 时间 | 20 秒 |
| 文本搜索 | 跳过二进制文件和超过 2 MB 的文件 |
| 查询长度 | 200 个字符 |

符号链接会被列出，但永远不会被跟随。从 `/` 开始的搜索会跳过 `/proc`、`/sys` 和 `/dev`。达到某个限制时，面板会说明：请在更小的文件夹中搜索，或使用更准确的词。

## 压缩和解压 {#compress-and-extract}

### 压缩 {#compress}

1. 勾选要打包的文件和文件夹。
2. 在选择栏中点击 **压缩**。
3. 输入 **压缩包名称（.zip 或 .tar.gz）**，然后点击 **确定**。

压缩包创建在当前文件夹中。符号链接和特殊文件会被排除。

### 解压 {#extract}

1. 打开压缩包的菜单，点击 **解压**。
2. 字段中填的是当前文件夹。要解压到别处，修改它，然后点击 **确定**。

面板可以解压 `.zip`、`.tar.gz`、`.tgz` 和 `.tar` 压缩包：

- 同名的已有文件会被覆盖。
- 压缩包中的符号链接和特殊文件会被跳过。
- 文件的权限为 `0644`，原来可执行的为 `0755`。在网站文件夹中，它们属于网站用户，在其他位置属于 root。
- 内容超过 20 GB 或文件超过 500,000 个的压缩包会被拒绝。

压缩和解压作为带实时日志的任务运行，所以离开页面后也会继续。

## 重命名或移动 {#rename-or-move}

打开项目的菜单，点击 **重命名**，输入新名称，然后点击 **确定**。新名称相对于当前文件夹解析，所以 `old/index.html` 或 `../index.html` 这样的路径会把项目移动到同一个网站内，或服务器的同一部分内的其他位置。

## 更改权限 {#change-permissions}

在 **权限** 列中点击项目的权限，或打开它的菜单并点击 **权限**。用八进制输入新值，例如文件用 `0644`，文件夹用 `0755`，然后点击 **确定**。

值最大为 `0777`。这里不能设置 setuid、setgid 和粘滞位。

**属主** 列显示属主和属组。文件管理不会更改属主。请用 [终端](./system#terminal) 来做，例如用网站自己的用户运行 `chown -R example_com:example_com /var/www/example.com/public`。

## 删除文件和回收站 {#delete-files-and-the-trash}

1. 勾选项目，或打开某个项目的菜单，点击 **删除**。
2. 默认情况下，项目会进入回收站：点击 **移到回收站**。
3. 要跳过回收站，勾选 **永久删除（不经过回收站）**，然后点击 **永久删除**。

::: danger
永久删除的项目（包括文件夹及其所有内容）无法恢复。
:::

### 从回收站恢复 {#restore-from-the-trash}

1. 要找回某个网站的文件，打开该网站的某个文件夹；要找回服务器其他部分的文件，打开网站之外的任意文件夹。
2. 点击 **回收站**。
3. 点击项目旁边的 **恢复**。

每个网站有自己的回收站，服务器的其他部分共用一个。项目会回到它原来的路径，带着原来的属主和权限。缺失的上级文件夹会被创建。如果那个路径上现在有别的东西，恢复会被拒绝：请先把它移开。

在回收站中，你还可以 **删除** 某个项目使其彻底消失，或点击 **清空回收站**。列表显示最近删除的 1,000 个项目。

### 项目保留多久 {#how-long-items-stay}

项目在回收站中保留 **30 天**。面板每小时检查一次，彻底删除更早的项目。

- 回收站保存在 `/var/lib/panel-trash/<domain>`，服务器其他部分的保存在 `/var/lib/panel-trash/_server`。只有 root 能读取它，所以网站用户无法访问自己已删除的文件。
- 回收站中的项目仍然占用磁盘空间。很大的文件请永久删除。
- 大于 1 GB、而且与回收站不在同一块磁盘上的项目无法移进回收站。请改为永久删除它。
- 删除网站也会删除它的回收站。
