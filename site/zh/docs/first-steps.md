# 入门步骤

[安装 Nefo](./install) 之后，用安装程序打印的地址和密码登录，在配置页面上选择软件，修改密码，开启双因素认证，给面板一个它自己的域名，然后创建第一个网站、设置备份并运行安全检查。每一步都很简短。

请按顺序完成这些步骤。每一步都链接到有详细说明的页面。

## 登录 {#sign-in}

1. 打开安装程序打印的 URL，例如 `https://203.0.113.10:28443/k3x9p2qa7m1z/`。
2. 接受浏览器的证书警告。面板有了自己的证书后，这个警告就会消失（见 [下文](#give-the-panel-its-own-domain)）。
3. 在 **用户名** 中输入 `admin`，再输入安装程序给出的密码，然后点击 **登录**。

如果丢失了 URL 或密码，在服务器上运行 `nefo info` 或 `nefo reset-password`（见 [命令行](./cli)）。

## 配置服务器 {#set-up-the-server}

在新服务器上，你登录后面板会立即打开 **配置这台服务器**。你在一个页面上选择服务器需要的东西，面板会一次性把它们逐个装好。

1. 选择 **Web 服务器**：**Nginx**（推荐）；需要 `.htaccess` 文件的网站选 **Apache**；**OpenLiteSpeed**；或者不放网站的服务器（例如只运行 Docker 应用的服务器）选 **无**。
2. 勾选一个或多个 **PHP 版本**。Web 服务器总会同时带上发行版自带的 PHP 版本。其他版本在 Ubuntu 和 Debian 上来自 `packages.sury.org/php` 软件源，面板会把它添加到服务器上。这里不提供已过生命周期的旧版本：如果某个旧网站需要，请从 **软件** 页面安装。
3. 选择 **数据库服务器**：**MariaDB**（推荐）、**MySQL**（在“软件”页面提供它的系统上），或 **无**。在 **MariaDB** 下可以选择它的版本：发行版自带的版本（默认），或者 MariaDB 自己软件源中的某个 LTS 系列，例如 **来自 MariaDB 的 11.4 LTS**（在它比发行版的版本更新时）。见 [MariaDB 版本](./databases#mariadb-versions)。
4. 勾选你需要的 **附加组件**：Redis、Node.js、Python、Docker、Adminer 和 Web 防火墙。ClamAV 只在 2 GB 或以上内存的服务器上提供；PostgreSQL 和 Memcached 在“软件”页面提供它们的系统上提供。
5. 检查底部的摘要。它会显示服务器的 CPU、内存和可用磁盘，以及你的选择大约会增加多少内存和磁盘占用。如果选择可能放不下，会有警告提示，但你仍然可以安装。
6. 点击 **安装**。

页面一开始给出的选择会适合服务器的内存：Nginx、最新的 PHP 版本和 MariaDB，内存约 1.5 GB 起再加上 Redis。Docker 和其他附加组件从不替你勾选。

磁盘数字包括：软件包安装后占用的空间、apt 在 `/var/cache/apt/archives` 中保留的已下载软件包副本（**系统** 页面 **清理** 下的 **已下载的软件包** 可以删除它们）、数据库服务器最初的数据文件，以及 ClamAV 的病毒库。在从未下载过软件包列表的服务器上，它还包括这些列表，摘要会说明其中有多少是列表：Ubuntu 22.04 约 450 MB，24.04 约 300 MB，26.04 约 250 MB，Debian 12 约 155 MB，Debian 13 约 175 MB。

日志会显示每个部分的安装过程，整个配置是一个任务。如果某个部分失败，配置会在那里停止，并告诉你哪些已经装好。解决问题后，再次点击 **安装**：已经安装的部分会被跳过。

如果想自己配置服务器，点击 **暂时跳过**。之后随时可以从 **软件** → **重新运行配置** 再次运行配置，或在服务器上运行 [`nefo setup`](./cli#nefo-setup)。你也可以 [在安装 Nefo 时配置服务器](./install#set-the-server-up-in-the-same-run)。

配置完成或被跳过之后，以及在已经有 Web 服务器或网站的服务器上，面板登录后不再打开配置页面。

### 容器形式的 VPS {#a-vps-that-is-a-container}

有些 VPS 是容器（LXC、OpenVZ），它们的 `/proc/meminfo` 可能显示整台宿主机的内存，而不是你的内存。这时 Nefo 会读取容器自己的限制（内存 cgroup），并在所有地方使用它：仪表盘、历史图表和告警、这个配置页面的内存数字、应用商店的内存检查，以及它为 MariaDB、MySQL、PostgreSQL、Redis 和 Memcached 选择的设置。这种情况下，仪表盘会在内存旁边显示“容器限制”。ClamAV 在这个限制达到 2 GB 时才提供。

## 修改密码 {#change-the-password}

把安装程序给出的密码换成一个保存在密码管理器中的密码。

1. 在左侧菜单中打开 **账户**。也可以从右上角的账户菜单打开：**密码与 2FA**。
2. 在 **修改密码** 下，填写 **当前密码**、**新密码** 和 **再次输入新密码**。新密码需要 12 到 72 个字符。
3. 点击 **修改密码**。

面板会在所有设备上退出登录。请用新密码重新登录。

## 开启双因素认证 {#turn-on-two-factor-authentication}

开启双因素认证后，登录需要你的密码和身份验证器应用（例如 Google Authenticator、Authy 或 2FAS）中的 6 位验证码。在你开启之前，仪表盘和通知菜单会显示“双因素登录已关闭”。

1. 打开 **账户**。
2. 在 **双因素认证** 下，点击 **设置**。
3. 用身份验证器应用扫描二维码，或手动输入 **设置密钥**。
4. 输入应用显示的 6 位验证码，然后点击 **开启**。

从此以后，登录页面会在密码之后要求输入 **双因素验证码**。

::: warning 留一条退路
如果手机丢了，只能在服务器上用 `nefo reset-password --disable-2fa` 关闭双因素认证（见 [故障排除](./troubleshooting#lost-your-2fa-phone)）。请保持 SSH 访问可用，或者把设置密钥保存在安全的地方。
:::

## 安装 Web 服务器和 PHP {#install-a-web-server-and-php}

网站需要 Web 服务器。Nefo 每台服务器运行一个。如果 [配置](#set-up-the-server) 时已经装好，跳过这一步。

1. 打开 **网站**。在新服务器上，它会显示 **安装 Web 服务器**。
2. 选择一个 Web 服务器：
   - **Nginx**：快速、轻量，除非你的网站需要 `.htaccess` 文件，否则是最佳选择。
   - **Apache**：读取 `.htaccess` 文件，很多 WordPress 插件和来自共享主机的网站都依赖它。它占用的内存稍多。
   - **OpenLiteSpeed**：读取 `.htaccess` 文件中的重写规则，并内置 LiteSpeed Cache。它来自 LiteSpeed 自己的软件源。
3. 点击安装按钮，例如 **安装 Nginx**。

面板会安装 Web 服务器和发行版自带的 PHP 版本；如果防火墙（ufw）已开启，还会开放 80 和 443 端口。这需要一到三分钟，页面上会显示进度。

以后要换成另一个 Web 服务器，必须先删除所有网站。在 **软件** 页面添加更多 PHP 版本、MariaDB 和其他组件。见 [软件](./software)。

## 给面板一个它自己的域名 {#give-the-panel-its-own-domain}

有了自己的域名，面板就能获得免费的 Let's Encrypt 证书，浏览器的警告也会消失。你需要先装好 Web 服务器，因为由它在 80 端口上响应 Let's Encrypt。

1. 在你的 DNS 服务商处，为 `panel.example.com` 这样的名称创建一条 A 记录，指向服务器的 IP 地址。它必须直接指向服务器，前面不能有代理或 CDN（使用 Cloudflare 时，选择“DNS only”（仅 DNS））。
2. 确认 80 端口已开放，服务商的云防火墙中也要开放。
3. 在面板中打开 **设置** → **证书**。
4. 在 **面板域名** 中输入 `panel.example.com`，然后点击 **获取证书**。

面板会先检查该域名能否到达这台服务器，然后向 Let's Encrypt 申请证书。它会在一分钟内启用新证书，并显示新地址，例如 `https://panel.example.com:28443/k3x9p2qa7m1z/`。从此请使用这个地址：面板保持相同的端口和秘密路径。如果用 IP 地址访问，浏览器会再次警告，因为证书是为域名签发的。

证书会自动续期。要改回自签名证书，在同一页面上点击 **删除**。

如果申请失败，见 [故障排除](./troubleshooting#a-certificate-request-fails)。

## 创建第一个网站 {#create-your-first-website}

1. 把域名（例如 `example.com`）的 A 记录指向服务器的 IP 地址。
2. 打开 **网站**，点击 **添加网站**。
3. 在 **域名** 中输入域名，不带 `http://` 或 `www.`。如果两个名称都要，保持勾选 **同时响应 www.example.com**。
4. 选择 **类型**：一个 PHP 版本、**静态（仅 HTML）**、一个应用（Node.js、Python 或 Java），或者到另一个地址的反向代理。
5. 点击 **创建网站**。
6. 点击网站旁边的 **开启 HTTPS**，获取免费证书。

用 **文件** 页面或通过 SFTP 把文件上传到 `/var/www/example.com/public`。如果要安装 WordPress 或其他应用，请使用 **应用商店**。见 [网站](./websites)、[SSL 证书](./ssl) 和 [应用商店](./apps)。

## 设置备份 {#set-up-backups}

1. 打开 **备份**。
2. 在 **自动备份** 下，点击 **添加计划**。
3. 选择备份什么（一个网站、一个数据库或一个文件夹）、多久备份一次，以及 **保留的备份数量**。
4. 点击 **保存计划**。

网站备份包含网站的文件和关联到它的数据库。备份保存在服务器的 `/var/backups/panel` 中。添加 **远程存储**（S3 兼容存储、SFTP 或 Google Drive，可选加密），这样即使服务器丢失，也还有一份副本。见 [备份](./backups)。

## 开启防火墙 {#turn-on-the-firewall}

如果仪表盘显示“防火墙已关闭”，那么程序打开的每个端口都能从互联网访问。

1. 打开 **防火墙与 SSH**。
2. 点击 **开启防火墙**。

面板会保持 SSH 和面板自己的端口开放。如果页面提示没有安装 ufw，先用 `apt install ufw` 安装它。见 [安全](./security)。

## 运行安全检查 {#run-the-security-check}

1. 打开左侧菜单 **安全** 分组中的 **安全检查**。
2. 点击 **运行检查**。
3. 修复 **待修复** 下列出的问题，从 **严重** 开始：每项发现都有一个按钮通往修复它的页面。

之后检查每天会自动运行一次，仪表盘会显示它的发现。见 [安全检查](./security-check)。
