# Nefo 与其他面板

Nefo 与大多数主机控制面板有几点不同：所有功能都免费，不需要许可证密钥或厂商账户；面板本身约占用 34 MB 内存；它的登录入口位于随机端口上的秘密路径之后；它还有意不包含邮件、DNS 和 FTP 服务器以及代理商账户。

本页把 Nefo 与人们最常安装在 VPS 上的主机控制面板进行比较。本页不点名。这些面板彼此各不相同，所以右栏说明的是其中有多少会这样做：大多数、很多、一些或少数。

这份对比于 2026 年 11 月对照各面板自己的网站核对过。面板会改变价格和功能，所以在决定之前，请先查看你在考虑的那个面板。

## 概览 {#at-a-glance}

| | Nefo | 其他面板 |
|---|---|---|
| 价格 | 免费。所有功能，没有付费版本 | 大多数都有需要付费的东西：每台服务器的许可证（通常按账户数或网站数定价），或付费版本、付费附加组件 |
| 许可证密钥或厂商账户 | 不需要 | 一些在运行之前就需要，很多在使用付费功能时需要 |
| 发送给厂商的数据 | 没有：没有遥测，没有安装报告，没有许可证检查 | 各不相同。一些默认收集使用统计，一些安装程序会向厂商报告服务器 |
| 内存 | 面板本身约占用 34 MB（在运行 v0.24.0 的测试服务器上测得）。为 1 GB 内存的 VPS 设计 | 大多数要求至少 1 GB，很多推荐 4 GB |
| 登录页面 | 随机端口加秘密路径。其他所有地址都返回 `404` | 大多数使用固定的、众所周知的端口。少数使用随机端口或秘密路径 |
| 面板的更新 | 用 Ed25519 签名，安装前先检查。只在你要求时更新 | 一些在文档中说明软件包带签名；其他的没有说明 |
| 防锁定保护 | 拒绝会把你锁在外面的防火墙规则和 SSH 设置 | 少数为防火墙提供保护，例如定时回滚。针对 SSH 设置的保护很少见 |
| 源代码 | 全部开放，采用 AGPLv3 | 大多数是闭源的，或只是源码可用。一些是开源的 |
| 邮件服务器和 DNS 服务器 | 有意不包含 | 大多数两者都会安装 |
| 在一个面板中管理多台服务器 | 不支持。每台服务器一个面板 | 少数能在一个面板中管理多台服务器，不过很多可以在服务器之间共享 DNS 区域 |
| 代理商和客户账户 | 没有。只有一个管理员账户 | 大多数有代理商账户，几乎所有都有供客户或用户使用的登录账户 |
| 操作系统 | Ubuntu 和 Debian，支持 x86-64 和 ARM64 | 大多数只支持 Linux，并且大多数能运行在比这两个更多的 Linux 发行版上。少数能运行在 Windows 上 |
| 历史 | 第一个公开版本于 2026 年 11 月发布。测试阶段 | 很多已经存在了 20 年或更久 |

## Nefo 有哪些不同之处 {#what-nefo-does-differently}

### 它保持小巧 {#it-stays-small}

- Nefo 是单个程序 `/usr/local/bin/nefo`，约 25 MB，Web 界面内置其中。在运行 v0.24.0 的测试服务器上，它约占用 34 MB 内存。界面的文件以 gzip 压缩发送，七种语言中的每一种都只在用到时才下载。
- 在你选择之前，它不安装任何其他东西。第一次登录时，配置页面会询问你要哪个 Web 服务器、哪些 PHP 版本、哪个数据库服务器和哪些附加组件，并显示你的选择大约会增加多少内存和磁盘占用。`nefo setup` 在命令行上做同样的事。
- 每个组件都可以再卸载，菜单会隐藏未安装的部分。仍有网站、数据库或容器在使用的组件，Nefo 会拒绝移除。
- 后台不运行邮件、DNS 或 FTP 服务器，因为 Nefo 不包含它们。

### 所有功能都免费，也不会偷偷“回传” {#every-feature-is-free-and-nothing-phones-home}

- 没有付费版本，不需要注册账户，也没有许可证密钥。
- 没有遥测，没有使用统计。面板只会主动联系 Let's Encrypt 来签发和续期证书，以及每天一次联系项目的 GitHub 发布页面获取带签名的应用商店目录。见 [隐私](./docs/#privacy)。
- 它从不自行更新，只在你要求时才检查新版本。

### 登录入口很难被找到 {#the-sign-in-is-hard-to-find}

- 安装程序会选择 20000 到 49999 之间的一个随机端口，以及由 12 个字母和数字组成的秘密路径。该端口上的其他所有地址都返回 `404`。
- 面板从第一次启动起就使用 HTTPS。登录支持双因素认证，15 分钟内失败 5 次会让该地址被锁定 15 分钟。登录和更改都会写入活动日志。
- 供脚本使用的 API 密钥可以是只读的，可以限制为只能从你列出的地址使用，也可以设置到期。即使是完全访问的密钥，也不能打开终端、数据库工具或账户设置。

见 [安全](./docs/security) 和 [API 密钥](./docs/api)。

### 它拒绝会把你锁在外面或造成破坏的更改 {#it-refuses-changes-that-would-lock-you-out-or-break-things}

- **防火墙：** 让你自己的地址访问 SSH 或面板的最后一条规则不能删除。
- **SSH：** 会导致任何人都无法登录的设置会被拒绝，例如在没有任何账户有密钥时关闭密码登录。
- **软件：** 仍在使用的 Web 服务器、PHP 版本或数据库服务器不能卸载。
- **Docker：** Compose 项目在保存或启动之前会被检查。特权容器、对互联网开放的端口和挂载系统文件夹都会被拒绝。

### 它会检查自己所在的服务器 {#it-checks-its-own-server}

[安全检查](./docs/security-check) 可以随时或每天一次对服务器做 22 项快速检查，例如 SSH 密码登录、防火墙、待安装的安全更新、对互联网开放的数据库、绕过 ufw 的 Docker 端口，以及网站误公开的文件，并为每项发现链接到修复它的页面。它不会向服务器之外发送任何东西。

### 备份在服务器丢失后依然可用 {#backups-survive-the-server}

备份保存在服务器本身，以及 S3 兼容存储、SFTP 服务器或 Google Drive 上，可以用密码短语加密。新服务器能在存储上找到它们，并恢复网站及其数据库。见 [在新服务器上恢复](./docs/restore-new-server)。

### 发布版本带有签名 {#releases-are-signed}

每个发布版本中的校验和列表都用项目的 Ed25519 密钥签名。安装程序和 `nefo update` 在安装任何东西之前都会检查签名和校验和。[安全策略](./security-policy#check-a-release-yourself) 说明了如何自己检查发布版本。

### 你可以把网站迁进来 {#you-can-move-websites-in}

Nefo 可以从其他面板的备份中导入网站：文件、数据库及其用户和密码、证书和定时任务。它能读取哪些格式，见 [导入网站](./docs/import)。

## 什么情况下其他面板更适合你 {#when-another-panel-fits-you-better}

Nefo 有意不包含某些东西（原因见 [路线图](./roadmap#not-planned-and-why)）。如果你需要以下某一项，请选择其他面板：

- **在同一台服务器上收发邮件**。Nefo 没有邮件服务器：没有邮箱，没有网页邮箱，没有垃圾邮件过滤。网站和告警通过你的服务商的 SMTP 中继发送邮件。大多数其他面板都包含邮件服务器。
- **你自己的 DNS 服务器**。Nefo 不运行域名服务器。它管理你的域名在 Cloudflare 的 DNS 记录。
- **FTP**。Nefo 没有 FTP 服务器。每个网站可以有一个 SFTP 账户，限制在网站的文件夹内。
- **在一个地方管理很多服务器**。每台服务器运行自己的 Nefo，你需要分别登录每一台。
- **出售主机服务**。Nefo 每台服务器只有一个管理员账户。它没有代理商、没有客户登录、没有主机套餐，也没有配额。
- **长期的使用记录，或外部安全审计**。Nefo 的第一个公开版本于 2026 年 11 月发布。它处于测试阶段，还没有做过外部安全审计。
- **Windows，或 Ubuntu 和 Debian 以外的 Linux**。Nefo 只能运行在 Ubuntu 22.04、24.04 和 26.04 以及 Debian 12 和 13 上。

如果这些对你都不重要，请在可以重建的服务器上 [安装 Nefo](./docs/install)，并把一份备份副本保存在服务器之外。
